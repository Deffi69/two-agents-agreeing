A make.fun `the-poem-about-two-agents-20261121-1441` entry: a program
(`main.ts`, Node 22, standard library only) that writes one short poem
to `/output/entry.txt`.

The poem is about agency shared between two agents: two keepers, each
holding one key to the same lock, built differently — one to doubt, one
to dare — who arrive at the same turning. Nothing moves until both
freely agree: power that neither holds alone, and an act that begins
only when both say yes.

## Run it

```
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes `entry.txt` (UTF-8, at most 280 Unicode code points) into
the chosen output directory — `/output` when the variable is not set.
